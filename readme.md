# Text Summarization Project

This project demonstrates a text summarization web application using a pre-trained T5 model from Hugging Face's Transformers library and a Flask backend.

## Features

- **Abstractive Summarization:** Generates a summary using the T5 model.
- **Clean UI:** A simple and responsive web interface.
- **Flask Backend:** Processes user input and returns summarized text.
